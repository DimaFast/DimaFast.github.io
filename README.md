# Медичний центр «Вербена»

Сайт на Next.js 16.4.6, React 19 і TypeScript. App Router збирає 27 статичних сторінок. Оригінальні URL збережені, профіль лікарки, яка вибула, повертає 404. Фони й медіа зберігаються локально. Компоненти каруселі, форми та мобільного меню працюють на клієнті.

## Анімації

`motion` відстежує появу секцій у полі зору, а CSS керує тривалістю та плавністю появи, переходами меню й анімацією колажу. `embla-carousel-react` керує каруселями послуг і відгуків, підтримує свайпи, стрілки клавіатури та навігацію кнопками. Налаштування операційної системи «Зменшення руху» вимикає декоративні анімації й робить переходи каруселей миттєвими.

## Запуск

Потрібні Node.js 22+ і npm.

```sh
npm ci
npm run dev
npm run build
npm start
```

## Маршрути

Кожна публічна сторінка має власну папку з `page.tsx` у `app/`. Групи Next.js у дужках організовують код за розділами. У URL входить назва папки сторінки.

| Група                   | Вміст                              | Приклад URL                                      |
| ----------------------- | ---------------------------------- | ------------------------------------------------ |
| `app/(services)/`       | Каталог і детальні сторінки послуг | `/ultrasound-diagnostics/`                       |
| `app/(doctors)/`        | Список лікарів і профілі           | `/shendera-anastasia-mikhailovna/`               |
| `app/(blog)/`           | Список статей і публікації         | `/why-is-it-important-to-do-cytology-regularly/` |
| `app/(medical-topics)/` | Сторінки за медичними напрямами    | `/uzd-hmelnytskyj/`                              |

Головна, контакти, ціни та інформація про центр лежать безпосередньо в `app/`. Для нової сторінки додайте її дані в `content/`, створіть `page.tsx` у відповідній групі й додайте метадані в `lib/seo.ts`. Карта сайту бере URL зі списків розділів і контенту. Перевірте, що нова сторінка відкривається за адресою з `sitemap.xml`.

`components/` містить секції й інтерактивні елементи. `lib/clinic.ts` містить контакти.

## Зображення та швидкість

Оригінали зберігаються в `public/media/`. Під час `npm run dev`, `npm run build` або `npm run typecheck` скрипт `prepare:images` генерує адаптивні WebP. Кожен похідний файл проходить перевірку пікселів після кодування, а файли, які важать більше за оригінал або стільки ж, відсіюються. Браузер обирає розмір через `srcset` і `sizes`. Розмір оригіналу залишається варіантом для більших екранів.

## Публікація на основному домені

Для публікації на `verbena-med.com.ua` зберіть сайт командою `SITE_INDEXABLE=true npm run build` і розмістіть вміст `out/` на хостингу зі звичайною обробкою помилок 404. Перед переключенням домену збережіть резервну копію попередньої версії. Нижче фрагмент для HTTPS-сервера Nginx на основному домені. Спрямуйте HTTP та www на його канонічну HTTPS-адресу.

```nginx
root /var/www/verbena/out;
index index.html;

# Існуючі посилання на попередню карту сайту.
location = /sitemap_index.xml { return 301 /sitemap.xml; }
location = /page-sitemap.xml { return 301 /sitemap.xml; }

gzip on;
gzip_types text/css application/javascript application/json application/xml image/svg+xml;
gzip_vary on;

location /_next/static/ {
    try_files $uri =404;
    add_header Cache-Control "public, max-age=31536000, immutable";
}

location /media/responsive/ {
    try_files $uri =404;
    add_header Cache-Control "public, max-age=31536000, immutable";
}

location / {
    try_files $uri $uri/ =404;
    add_header Cache-Control "no-cache";
}

error_page 404 /404.html;
```

Після переключення перевірте доступ без входу, статуси всіх URL із sitemap та відсутність `noindex` у метатегах і HTTP-заголовках HTML-сторінок. У Google Search Console та Bing Webmaster Tools надішліть `https://verbena-med.com.ua/sitemap.xml`. Перевірте, що `/sitar-lina-nikolaevna/` повертає HTTP 404, відсутній у sitemap та лишається доступним для повторного обходу. Для тимчасового прискорення приховування URL скористайтеся інструментом «Видалення» у Search Console. У приватній демонстрації сторінки мають `noindex`. Перевірте головну, ключові послуги та знятий профіль у «Перевірці URL». Карта запитів є в [SEO.md](docs/SEO.md).

## Стилі

CSS Modules лежать поруч із компонентами й містять їхні адаптивні правила та анімації. У `app/globals.css` залишаються палітра, базова типографіка, сітка та спільні стилі для кнопок і секцій.

## Форми

`components/contact-form.tsx` використовує React Hook Form і `zodResolver`. Схеми для швидкої консультації та повного повідомлення лежать у `components/contact-form.schema.ts`. Помилки відображаються біля відповідних полів.

У приватній копії форма готує лист на адресу центру й відкриває поштову програму відвідувача. Відвідувач натискає «Надіслати» в поштовій програмі. Дзвінок і месенджери також доступні з сайту.

Для прийому заявок безпосередньо з сайту налаштуйте погоджений із центром сервіс і задайте `NEXT_PUBLIC_BOOKING_ENDPOINT` перед збіркою. Форма надсилає POST JSON з полями `mode` (`callback` або `message`), `name`, `phone`, `email`, `message` та `website` (приховане поле для відсіву спаму). Запит із профілю лікаря містить додаткове поле `doctorName`. Успішна відповідь має містити `{"success":true}`. Сервіс має валідовувати дані, перевіряти поле `website`, обмежувати частоту запитів і дозволяти origin сайту, якщо API працює на іншому домені. Реквізити доставки повідомлень задаються в сервісі прийому заявок.

Ціни для загального прайсу та сторінок послуг беруться з `content/pricing.ts`. Перед переходом на основний домен підтвердьте з центром вартість онлайн-консультації, вакцинації та видалення папілом.
